# AI Workspace API

A production-oriented REST API built with FastAPI, PostgreSQL, Docker, and JWT authentication.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication
- Pydantic
- Docker
- Pytest
- Git & GitHub

## Features

- User registration
- User login
- JWT access tokens
- Protected user endpoints
- Get all users
- Get user by ID
- Update user
- Delete user
- PostgreSQL database
- Dockerized application
- Automated API tests
- Environment-based configuration
